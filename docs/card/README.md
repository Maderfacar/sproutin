## 內容

**正面**　Sproutin 標誌 · 陳識翔 · TEL 0938-652-927 · 產品一句話
**背面**　森綠滿版 + QR（掃進產品介紹）+ 三行重點 + 網址

視覺與產品、DM 同一套「清葉」設計語言（米白紙、森綠、襯線標題）——
名片與簡介長得像同一件事，對方掃進去才不會覺得換了一家公司。

## QR

掃進去是 **DM 產品介紹**：`https://sproutin-kb91-theta.vercel.app/_dm`

- 容錯等級 **Q**（可容忍 25% 髒污磨損）· 33 模組 · 印刷尺寸 25.5 mm（每模組約 0.66 mm）
- SVG 本身含 4 個模組的靜區，外面再加一圈白磚 —— 靜區不足是掃不到的頭號原因
- **QR 直接內嵌在 `card.html` 裡**，不是 `<img src="qr.svg">`：這個檔案會被寄來寄去，
  只要有人單獨搬走 card.html，外部圖就變破圖，而那一面唯一的作用就是那張 QR

### 驗證方式

印在紙上的 QR 掃不到是無法補救的錯誤，所以**每次都真的解一次**，不是看它「長得像 QR」：

1. `qrcode` 產生 → `jsQR`（另一套實作）解回來，比對字串完全相同。
2. 再把**排版完成的背面**以約 384 dpi 拍成點陣圖（比實際印刷的 300 dpi 更嚴），
   在 25.5 mm 的實際尺寸下再解一次。

`build-card.mjs` 會自動跑第 1 步；找不到 `jsqr` / `pngjs` 時會明確警告，不會靜靜跳過。

## 重新輸出

```bash
node docs/card/build-card.mjs
```

產生 QR、內嵌進 `card.html`、驗證、輸出印刷 PDF 與 `preview.png`。需要本機有 Chrome 或 Edge。
要自動驗證再加裝：`npm i -D jsqr pngjs`。

只重生 QR（例如換了網址）：`node docs/card/build-card.mjs --qr-only`
**換網址時，`build-card.mjs` 的 `TARGET` 與 `card.html` 上那行網址文字要一起改。**

## 改設計

直接編輯 `card.html`，尺寸**一律用 mm**（這份檔案會被印刷廠拿去輸出，改成 px 會跑掉）。
螢幕預覽是兩倍放大、帶紅色裁切虛線；列印時這些會自動消失並回到實際尺寸。

想印職稱：把正面 `<p class="role" hidden>` 的 `hidden` 拿掉並填字。

## 送印前要注意

- **字型**：PDF 已內嵌 Noto Serif TC。若印刷廠要求文字轉外框，請告知，需另外處理。
- **色彩**：這是 RGB 檔。多數數位印刷可直接吃；若對方要 CMYK，森綠 `#2f6b4f`
  轉換後會略暗，建議先看數位樣。
- **網址**：目前指向 `*.vercel.app` 的網址。**若之後會換成自己的網域，名片就會失效** ——
  建議先確定網域再印。
